Départ — îlot de filtre

Votre enseignant·e vous donne ce dossier. Placez son contenu
pour obtenir exactement cet arbre :

  m10/ilot-filtre/config.exemple.php
  m10/ilot-filtre/config.php
  m10/ilot-filtre/bootstrap.php
  m10/ilot-filtre/src/Evenement.php
  m10/ilot-filtre/src/EvenementManager.php
  m10/ilot-filtre/api/evenements.php
  m10/ilot-filtre/js/filtre.js
  m10/ilot-filtre/liste.php

Le dossier data/ et ce README ne font pas partie de l’arbre à
rendre.

Ouvrez d’abord projets/05-ilot-filtre/1-COURS.pdf, puis
projets/05-ilot-filtre/2-ATELIER.pdf.

Si vous avez un annuaire de 8 à 12 objets, copiez-le ici puis
ajoutez api/ et js/. Sinon, partez de ce dossier : la liste
montre déjà tous les objets, le filtre n’est pas encore branché.

Depuis ce dossier :

  php -S localhost:8080

Puis ouvrez http://localhost:8080/liste.php
