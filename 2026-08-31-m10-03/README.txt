Départ — CRUD + layout

Votre enseignant·e vous donne ce dossier. Placez son contenu
pour obtenir exactement cet arbre :

  m10/crud/config.exemple.php
  m10/crud/config.php
  m10/crud/bootstrap.php
  m10/crud/inc/header.php
  m10/crud/inc/footer.php
  m10/crud/src/Evenement.php
  m10/crud/src/EvenementManager.php
  m10/crud/liste.php
  m10/crud/fiche.php
  m10/crud/formulaire.php
  m10/crud/supprimer.php

Le dossier data/ et ce README ne font pas partie de l’arbre à
rendre.

Ouvrez d’abord projets/03-crud/1-COURS.pdf, puis
projets/03-crud/2-ATELIER.pdf.

Si vous avez le projet 02, copiez-le ici puis ajoutez inc/,
formulaire.php et supprimer.php. Sinon, partez de ce dossier :
la liste et la fiche fonctionnent déjà ; le cadre n’est pas
encore partagé.

Depuis ce dossier :

  php -S localhost:8080

Puis ouvrez http://localhost:8080/liste.php
